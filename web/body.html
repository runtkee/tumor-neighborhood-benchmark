Load a cell table from your tumor imaging, map its columns, and see how your patients compare with public patients on the same tests: do T cells avoid neutrophils, gather near macrophages, or change state when touching them?

Cell types

Assign each label in your file to a role. "Private-only neutrophil subset" (for example LOX-1+ PMN-MDSC) is analysed separately and shown next to public neutrophils, never pooled with them.

Rules are tried top to bottom; a cell takes the first rule it matches, otherwise "Other". Example: T cell = CD3 positive; neutrophil subset = CD66b and LOX-1 positive (put it above plain neutrophil).

T-cell readouts and bleed markers

Bleed markers are each cell type's own marker. The kit measures how much of it shows up inside touching T cells, which tells you how far contact comparisons can be trusted.

Share a summary (optional)

Per-patient effect sizes only, with each patient replaced by a random code. No cell-level data is included. Nothing is sent anywhere; you decide whether to pass it on. The key linking codes to your patients stays with you.

Key: random code → your patient ID (keep private, do not share)

Method: 10 µm = touching, 30 µm = nearby. Every test compares against cell labels shuffled within each image, so tissue layout is held fixed. Marker levels are within-image percentiles. Each patient gives one value. Identical to the Python kit (automated parity test). Reference sources: IMMUcan (Zenodo 10.5281/zenodo.12912567, CC BY 4.0), Schürch et al. 2020 CODEX (Mendeley 10.17632/mpjzbtfgfr.1, CC BY 4.0), SPATCH benchmark (Nat Commun 2025, summary statistics only).

The reference holds per-patient summary statistics derived by this kit from public datasets. It contains no cell-level data. Each source:

  • IMMUcan_IMC_panel1: IMMUcan consortium, imaging mass cytometry panel 1, 179 patients (breast, GI, GU, head & neck, thoracic). Zenodo 10.5281/zenodo.12912567. License CC BY 4.0. Neutrophils = CD15+MPO+.
  • CODEX_CRC_Schurch2020: Schürch et al., Cell 2020, 35 colorectal cancer patients, CODEX. Mendeley Data 10.17632/mpjzbtfgfr.1. License CC BY 4.0. "Granulocytes" = CD15+ (includes eosinophils).
  • SPATCH_*: SPATCH platform benchmark, Nat Commun 2025 (doi 10.1038/s41467-025-64292-3), one patient per cancer (colon, ovarian, liver), Xenium 5K and CosMx 6K. Data portal spatch.pku-genomics.org. Data license not stated on the portal; only derived summary statistics are included here.

Changes: all sources were re-processed with this kit's locked recipe (v2p). Cell-type labels were mapped to kit roles as listed in each dataset's manifest (kit_manifests/).
